# artist/:artistId/ [GET]

    Description: 
        Given a artist with ID artistId, provide basic details about the artist.

    Error:
        AccessError (after we have implemented user login):
            Invalid token

    Data Type:
        Parameters:
            {}
        Return Type:
            {
                artistId: int,
                artistName: String,
                rank: {
                    taiwan: 999 (int),
                    hong_kong: 123 (int),
                    and so on...
                }
                icon: String,
                type: String (actor, musician),
                popularity: int,
                sns: int,
                music: int,
                drama: int,
                spotifyLink: String,
                instaLink: String,
                youtubeLink: String,
                tiktokLink: String,
                country: String,
                popularityData: [popularity] (for chart)
                snsData: [sns] (for chart)
                music: [music] (for chart)
            }
